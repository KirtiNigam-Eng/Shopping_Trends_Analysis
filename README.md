# Shopping_Trends_Analysis
This project focuses on analyzing customer shopping behavior and purchasing trends using data analysis and interactive visualizations. The dashboard provides insights into customer spending patterns, age group purchases, product category performance, and overall sales trends to support better business decision-making.
